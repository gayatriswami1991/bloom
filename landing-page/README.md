# Bloom ad landing pages

- `index.html` English, `mr.html` Marathi. Generated by `python3 build.py` (layout) from the copy in `content.py`.
- `guide-en.pdf` / `guide-mr.pdf` is the lead magnet, generated by `python3 guide.py` (needs Chromium).
- Upload the whole folder (keep `assets/`). Images marked `assets/img/*` are frames taken from Bloom's own reels; website images (logo, doctor, before/after pairs) load from bloomhairtransplant.com.
- **Lead capture:** the 4-step assessment. With `FORM_ENDPOINT` empty (in `build.py`) the result screen shows a 1-tap "Send details on WhatsApp" button. Set it to a Zoho/Apps Script/Formspree URL to receive leads silently (payload includes name, phone, concern, timing, clinic, UTM params and gclid).
- **Celebrity block:** add photos to `assets/celeb/` (or paste URLs in `CELEB_URLS`) and re-run `build.py`. The section stays hidden while empty.
- Tracking events pushed to `dataLayer`: `lp_call`, `lp_whatsapp`, `lp_step1`, `lp_step3`, `lp_lead`, `lp_guide`, `lp_reel`, `lp_concern`. Paste GTM/Ads/Pixel snippets at the marked comment in `<head>`.
- Pages are `noindex`; remove that meta to allow indexing.
