# Bloom landing pages (ad traffic)

- `index.html` English, `mr.html` Marathi. Both are generated by `python3 build.py` from one template; edit copy in the `EN` / `MR` dictionaries and re-run.
- Images load from bloomhairtransplant.com. Reels are in `assets/reels/` (compressed, first 45 s of each).
- Upload the whole `landing-page` folder (keep `assets/`) to the host. In Elementor, use an HTML widget or a blank template page.
- `FORM_ENDPOINT` in `build.py`: leave empty and the quick form opens WhatsApp with the details prefilled; set a Zoho/Apps Script/Formspree URL to capture leads silently.
- The bottom form is the clinic's existing Zoho form. Tracking events (`lp_call`, `lp_whatsapp`, `lp_lead`, `lp_reel`) push to `dataLayer`; paste GTM/Ads/Pixel snippets at the marked comment in `<head>`.
- Pages are `noindex` so they do not compete with the main site. Remove that meta if you want them indexed.
